# ระบบเบิกจ่ายวัสดุสิ้นเปลือง — รุ่นใช้งานจริงแบบติดตั้งในองค์กร

## สิ่งที่มีให้
- ฐานข้อมูล SQLite เก็บข้อมูลจริงบนเครื่องเซิร์ฟเวอร์
- ผู้เบิก / ผู้ดูแลระบบ
- ค้นหาชื่อวัสดุและเลข MAC
- แสดงยอดคงเหลือ
- ส่งคำขอเบิก
- ผู้ดูแลอนุมัติ/จ่ายของ และระบบตัดสต็อกอัตโนมัติ
- เพิ่ม/แก้ไขวัสดุ
- ดูประวัติการเบิก
- ดาวน์โหลดรายงาน CSV
- รองรับการเปิดผ่านมือถือ/คอมพิวเตอร์ในเครือข่ายเดียวกัน

## วิธีติดตั้ง
ต้องมี Python 3.10+ ในเครื่องที่จะเป็นเซิร์ฟเวอร์

Windows:
1. เปิด Command Prompt ในโฟลเดอร์นี้
2. รัน `py -m venv .venv`
3. รัน `.venv\Scripts\activate`
4. รัน `pip install -r requirements.txt`
5. รัน `python app.py`
6. เปิดเบราว์เซอร์ที่ `http://127.0.0.1:5000`

## ให้มือถือ/เครื่องอื่นใน Wi-Fi เดียวกันเข้า
บนเครื่องเซิร์ฟเวอร์รัน `ipconfig` แล้วดู IPv4 เช่น `192.168.1.20`
จากมือถือเปิด `http://192.168.1.20:5000`

ถ้าเข้าไม่ได้ ให้เปิด Firewall ให้ Python รับการเชื่อมต่อ TCP port 5000

## บัญชีทดลอง
ผู้ดูแล: admin / admin123
ผู้เบิก: requester / 1234

ควรเปลี่ยนรหัสผ่านก่อนใช้งานจริง

## ข้อสำคัญก่อนนำไปใช้จริง
- เปลี่ยน SECRET_KEY
- สำรองไฟล์ inventory.db เป็นประจำ
- นำรายการวัสดุจริงและยอดสต็อกจริงเข้าแทนข้อมูลตัวอย่าง
- ตั้งเครื่องเซิร์ฟเวอร์ไว้ในเครือข่ายที่บริษัทควบคุม
- หากต้องเปิดใช้งานผ่านอินเทอร์เน็ตภายนอก ควรเพิ่ม HTTPS, ระบบจัดการผู้ใช้ และฐานข้อมูล/เซิร์ฟเวอร์ที่เหมาะกับ production
